Mobile checkout loses 47% of shoppers; desktop loses 19%.

A funnel analysis of 60,000 simulated store visitors, built with SQL and Python. Filter the funnel below to see where each group drops off.

How it was built

Raw events go into SQLite. One SQL view turns them into a strict, ordered funnel: unique users, each step after the one before it, all within 7 days of the first visit. Duplicate events are removed by taking each user’s first occurrence of every step.

MIN(CASE WHEN event_name = 'product_view' THEN event_ts END) AS t2,
...
CASE WHEN r2 = 1 AND t3 IS NOT NULL AND t3 >= t2
     AND t3 <= datetime(t1, '+7 days') THEN 1 ELSE 0 END AS r3

Python draws the charts and the flow diagram. The write-up ends with recommendations: audit the mobile checkout, add an alert on payment completion by device, and rebalance paid-search spend.
